# Sovereign AI

Sovereign AI คือระบบ Autonomous Agent ที่ออกแบบมาเพื่อการตัดสินใจและแก้ไขปัญหาผ่าน Pattern Recognition โดยตัดการทำงานที่ไม่จำเป็นของ LLM แบบดั้งเดิมออกไป เพื่อลดอาการ "คิดวน" และเน้นการใช้เครื่องมือ (Tool-based) อย่างมีประสิทธิภาพ

## Core Concepts
- **Pattern-Driven:** เรียนรู้และจัดหมวดหมู่ปัญหา แทนการเดาสุ่มคำตอบ
- **Tool-First:** เลือกใช้เครื่องมือ (Tools) ที่เหมาะสมตามประเภทของปัญหาโดยตรง
- **Self-Evaluation:** ตรวจสอบความถูกต้องของคำตอบเอง และแก้ไขสมมติฐานหากผลลัพธ์ไม่เป็นไปตามเป้าหมาย

## Key Components
1. **Perception Layer:** วิเคราะห์โครงสร้างข้อมูลเบื้องต้น
2. **Execution Engine:** ระบบรันคำสั่งที่แม่นยำ ไม่ผ่านการคาดเดา
3. **Critic Loop:** ขั้นตอนตรวจสอบผลลัพธ์แบบ Deterministic
